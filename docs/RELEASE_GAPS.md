# Publication-record actions after GitHub upload

The software package itself is ready for an initial GitHub release. The following external identifiers cannot exist until the repository is created:

1. Add the final GitHub repository URL to the repository metadata and manuscript.
2. Create release tag `v1.0.0`, connect the repository to Zenodo, publish the archive, and add the Zenodo DOI.
3. Update `CITATION.cff` with the complete manuscript author list when authorship is finalized.
4. Record the first public Git commit and release-asset checksum in the submission log.

These are publication-record actions, not missing analysis results. Do not invent the URL, DOI, or author list before they are finalized.
