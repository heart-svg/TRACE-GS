# Draft Code availability text

The TRACE-GS source code, exact cross-validation assignments, per-sample outer-fold predictions, statistical-analysis scripts, figure-generation scripts, software environments, and model configuration records are available at https://github.com/heart-svg/TRACE-GS (version 1.0.1). A frozen archival copy is available from Zenodo at https://doi.org/10.5281/zenodo.23584355. Raw genotype, transcriptome, and phenotype data are not redistributed and remain available from the original repositories under their respective access and licensing conditions; dataset-specific accession numbers and file mappings are listed in the Data availability statement and `docs/THIRD_PARTY_DATA.md`.

The GitHub release and Zenodo DOI were verified on 23 October 2026.
